# Contributing and updating this lab

This is a personal learning portfolio. If you adapt it, keep test results honest and clearly separate planned, author-reported, and evidence-backed findings.

## Before publishing an update
1. Verify the installed Wazuh version and agent status.
2. Run tests only against systems you own or are authorized to test.
3. Correlate each alert with the original source event.
4. Save real screenshots or sanitized log excerpts.
5. Remove secrets and redact details that should not be public.
6. Update the relevant detection and investigation document with actual results.

Do not submit credentials, sensitive logs, or fabricated evidence.
